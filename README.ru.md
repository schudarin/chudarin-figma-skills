# chudarin-figma-skills

Пять наборов инструкций, которые учат ИИ-агента работать в Figma: спланировать экраны, разобрать
существующую дизайн-систему, дизайнить, писать в файл без поломок, чинить отвязанные переменные.

Ставится один раз. Дальше вы работаете в чате — кидаете ссылку на Figma и говорите одной фразой,
что нужно. Код писать не надо, редактор кода открывать не надо.

[English version](README.md)

## Что делает каждый скил

| Скил | Вы пишете примерно так | Что происходит |
|---|---|---|
| `figma-plan-user-flows` | «Какие экраны нужны для оформления заказа?» | Получаете все экраны и состояния, точки входа и выхода, структуру страниц файла — до того, как что-то нарисовано |
| `figma-audit-design-system` | «Пройди по файлу и скажи, что есть в дизайн-системе» | Агент читает файл и отчитывается: компоненты, токены, паттерны, долг. Ничего не меняет, пока вы не попросите |
| `figma-design-screens` | «Задизайни экран настроек» · «Поменяй шапку на этом фрейме» | Сам процесс дизайна: откуда берётся стиль, бриф на каждый экран, проверки после, правки в согласованной работе по одному элементу |
| `figma-plugin-api-rules` | ничего — грузится сам | 390+ реальных отказов Figma Plugin API и обход каждого. Загружается до того, как агент что-то запишет в ваш файл |
| `figma-fix-variable-bindings` | «Переменные на этой странице отвалились, почини» | Находит отвязанные, осиротевшие и захардкоженные значения, показывает отчёт, привязывает обратно только после вашего подтверждения |

Всё это обычный Markdown. На вашей машине ничего не запускается и никуда не отправляется.

## Что нужно до установки

Три вещи, по порядку.

### 1. Место в Figma, которое пускает агента

Figma ограничивает агента не скилом, а типом места (seat):

- **План Starter либо место View или Collab на платном плане** — до 6 вызовов инструментов в месяц.
  Хватит один раз посмотреть, а не работать.
- **Место Dev или Full на планах Professional, Organization, Enterprise** — лимиты в минуту, те же,
  что у REST API Figma. Вот это рабочий вариант.

Запись в файл бесплатна, пока идёт бета Figma. Чтение считается по лимитам выше.

### 2. Claude Code

Claude Code — агент от Anthropic. Живёт в Терминале, это чёрное окно, а не редактор кода.

Откройте Терминал (⌘ + Пробел, наберите `Terminal`, Enter), вставьте строку и нажмите Enter:

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

Когда закончится, наберите `claude` и Enter — запустится чат. Выход — `/exit`.
Полная инструкция: [docs.claude.com/en/docs/claude-code/setup](https://docs.claude.com/en/docs/claude-code/setup).

### 3. Связь с Figma

У Figma есть свой плагин для Claude Code. В нём и соединение (MCP-сервер), и собственные инструкции
Figma для агента — эти скилы надстраиваются над ними. В Терминале:

```bash
claude plugin install figma@claude-plugins-official
```

Закройте Claude Code и запустите заново. Потом наберите в чате `/mcp`, выберите `figma` и пройдите
вход — Figma откроется в браузере и один раз попросит разрешить доступ.

## Установка скилов

Две строки в Терминале:

```bash
claude plugin marketplace add schudarin/chudarin-figma-skills
claude plugin install chudarin@chudarin
```

Закройте Claude Code и запустите заново. Те же две команды работают и внутри чата — как
`/plugin marketplace add …` и `/plugin install …`.

## Проверить, что встало

```bash
claude plugin details chudarin@chudarin
```

В списке пять скилов. Внутри чата они называются `chudarin:figma-design-screens`,
`chudarin:figma-plugin-api-rules` и так далее — агент подхватывает их сам, когда задача совпадает,
но можно назвать нужный напрямую.

## Откуда запускать

Заведите по папке на продукт и всегда запускайте Claude Code из неё:

```bash
mkdir -p ~/Design/my-product
cd ~/Design/my-product
claude
```

Папка важна. На первом запуске `figma-design-screens` задаёт максимум два вопроса — есть ли
дизайн-система, есть ли готовые экраны — и записывает ответы в `.claude/design.md` внутри этой
папки. Все следующие сессии читают файл, а не спрашивают вас заново. Запустите из другой папки —
начнёте с нуля.

## Первая задача

1. В Figma правый клик по фрейму или странице → **Copy link to selection**.
2. В Терминале: `cd ~/Design/my-product`, затем `claude`.
3. Вставьте ссылку и добавьте одну фразу о том, что нужно.

```
https://figma.com/design/…  — разбери эту страницу и скажи, что есть в дизайн-системе
```

```
https://figma.com/design/…  — спланируй экраны для восстановления пароля
```

```
https://figma.com/design/…  — отступы у этих карточек захардкожены, верни их на переменные
```

Ссылку кидайте всегда. Без неё агент угадывает, какой файл и какая страница имеются в виду, и
угадывает мимо.

## Какой скил когда

- «Какие экраны нужны под эту фичу?» → `figma-plan-user-flows`
- «Что есть в дизайн-системе, где долг, задокументируй» → `figma-audit-design-system`
- «Задизайни / поменяй / пересобери этот экран» → `figma-design-screens`, он сам подтягивает
  `figma-plugin-api-rules`
- Любая запись в Figma → `figma-plugin-api-rules`
- «Переменные отвалились / захардкожены / Figma пишет „Variable was deleted“» →
  `figma-fix-variable-bindings`

## Обновить и удалить

```bash
claude plugin update chudarin@chudarin      # свежая версия, применяется после перезапуска
claude plugin uninstall chudarin@chudarin   # удалить
claude plugin list                          # что стоит сейчас
```

## Если не работает

| Что видите | Что это значит | Что сделать |
|---|---|---|
| Агент пишет, что не может достучаться до Figma | Соединение не авторизовано | Наберите `/mcp`, выберите `figma`, войдите через браузер |
| Останавливается после нескольких чтений | Лимит места: 6 вызовов в месяц на Starter, View, Collab | Попросите место Dev или Full на платном плане |
| Чтения начали отваливаться ближе к вечеру | Лимит частоты у аккаунта в Figma. На плане Professional мы видим примерно 70–100 чтений в день на все инструменты, сброс в 00:00 UTC | Продолжите завтра или разбейте работу на дни |
| Агент работает не в том файле или не на той странице | Ссылки не было, он угадал | Кидайте ссылку каждый раз. И поставьте скил, который спрашивает до действия — см. ниже |
| Скилы не появились | Плагин стоит, но сессия старая | Закройте Claude Code и запустите заново |
| Агент поменял то, что не просили | Figma хранит историю файла | **File → Show version history**, восстановите прошлую версию |

## Что поставить рядом

Эти скилы решают, *как* работать в Figma, когда задача уже ясна. Они не решают, *какая* задача.
Лучшие прогоны выходят в паре со скилом, который тормозит агента до первого действия и спрашивает,
какой проект и какой файл. В Claude Code мы держим `superpowers` от Anthropic
(`claude plugin install superpowers@claude-plugins-official`): на фразу «добавь кнопку» первым
срабатывает `brainstorming`, просит ссылку на файл и только потом передаёт дальше. Подойдёт любой
аналог. Без него агент начнёт не с той страницы.

Ещё пригодится свой скил под тексты — подписи кнопок и текст интерфейса. Эти скилы ставят текст на
место, но не пишут его.

## Другие агенты и установка руками

<details>
<summary>Codex или Claude Code без системы плагинов</summary>

Каждый скил — это папка: `SKILL.md` + `references/` + `agents/openai.yaml` для Codex. Клонируйте
репозиторий и слинкуйте папки туда, где ваш агент ищет скилы.

```bash
git clone https://github.com/schudarin/chudarin-figma-skills ~/chudarin-figma-skills
```

**Claude Code** — `~/.claude/skills/` для всех проектов или `<project>/.claude/skills/` для одного:

```bash
mkdir -p ~/.claude/skills
for s in ~/chudarin-figma-skills/skills/*; do ln -sfn "$s" ~/.claude/skills/; done
```

**Codex** — `~/.agents/skills/` для всех проектов или `<repo>/.agents/skills/` для одного. Вызов
явно — `$skill-name`; неявный вызов включён у всех пяти.

```bash
mkdir -p ~/.agents/skills
for s in ~/chudarin-figma-skills/skills/*; do ln -sfn "$s" ~/.agents/skills/; done
```

После `git pull` прогоните цикл заново, чтобы подтянуть обновления.

На любом другом агенте это обычный Markdown — отдайте `SKILL.md` агенту как контекстный файл перед
работой с Figma.

В любом случае нужен MCP-сервер Figma и собственные инструкции Figma `figma-use`, загруженные до
первого вызова `use_figma`: в Claude Code их даёт плагин Figma, в остальных местах — MCP-ресурс
`skill://figma/figma-use/SKILL.md`.

</details>

## Как дополнять

У каждого скила описан свой протокол расширения; у `figma-plugin-api-rules` он в конце
[`SKILL.md`](skills/figma-plugin-api-rules/SKILL.md). Факты про один конкретный файл Figma — ID
нод, местные договорённости — сюда не идут. Держите их в `<project>/.claude/design.md` или в своих
заметках.
